# 🍀 Yumika Luck - Farm & Master Financial Tracker

**Yumika Luck** is a comprehensive, cloud-synced web application built for farmers and homestead managers to track crop lifecycles, daily harvest auctions, expenses, chemical stock inventory, and spray logs across multiple projects.

---

## 🚀 Key Features

1. **🌐 All Crops Master Summary:** 
   - View an overall financial rollup of all your agricultural projects combined.
   - Filter views instantly by **Overall**, **Completed**, or **In Progress** crops.
2. **📦 Yield & Auction Entry Management:**
   - Log harvest units/bags by quality grade (*High*, *Medium*, *Low*).
   - Automated calculations for gross sales, fixed transport, market rent, and commissions (supported by both **Percentage %** and **Flat Amount ₹**).
3. **💸 Comprehensive Expense Tracker:**
   - Track expenses by contributor ("Spent By") with custom name management.
   - Dynamic real-time calculation of total investment straight from the expense ledger.
   - Visual SVG pie chart breakdown of expenditures.
4. **🧪 Chemical Stock Inventory & Spray Log:**
   - Manage fertilizer, fungicide, and pesticide stock balances.
   - Log spray applications that **automatically deduct** from your remaining stock inventory.
   - Track crop age in **DAS (Days After Sowing/Start)** automatically based on the crop start date.
5. **☁️ Cloud Sync & Export:**
   - Real-time synchronization using **Firebase Realtime Database**.
   - Export individual crop data or master summaries to **CSV**.
   - Quick one-click **WhatsApp sharing** for financial summaries.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Backend / Database:** Firebase Realtime Database
- **Hosting:** GitHub Pages
